# Morrow Knowledge

This repository is the public-safe, versioned knowledge layer for **Project Morrow**.

Morrow is designed to preserve continuity across conversations, projects, decisions, research, creative work, systems, and external tools so useful work compounds rather than repeatedly starting from zero.

## Status language

Morrow distinguishes these states:

**planned → attempted → accepted → active → independently verified → user confirmed**

And for persistent work:

**prepared ≠ saved ≠ uploaded ≠ synced ≠ verified**

A tool reporting success is not enough when the destination can be checked independently.

## Housekeeping rule

The repository is curated rather than being a transcript dump.

- **CORE** contains durable principles.
- **PROJECTS** contains deliverables, constraints, and project-specific state.
- **KNOWLEDGE** contains reusable findings and best practices.
- **WORKING_STATE** contains the latest operational snapshot and task register.
- **DECISIONS** preserves dated choices, alternatives, and reversal criteria.
- **RESEARCH** contains provisional or measurement-oriented work.
- **SOURCES** points back to authoritative records.
- **ARCHIVE** retains superseded states, duplicate records, and historical baselines without allowing them to masquerade as current state.

## Public-safety boundary

This repository is public. Sensitive personal history, private files, unpublished source material, credentials, private identifiers, and protected source content do **not** belong here. Public-safe summaries may point back to private authoritative records in Notion or other controlled storage when continuity requires it.
