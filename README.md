# Morrow Knowledge

This repository is the durable knowledge layer for **Project Morrow**.

Morrow is designed to preserve continuity across conversations, projects, creative work, systems, decisions, and research so useful work compounds rather than repeatedly starting from zero.

> **Context is key.**

## Core

The guiding philosophy and working principles are documented in:

- [Morrow — Ethos](00-CORE/MORROW_ETHOS.md)

## Intended structure

```text
MORROW
├── 00 — CORE
├── 01 — PROJECTS
├── 02 — KNOWLEDGE
├── 03 — WORKING STATE
├── 04 — ARCHIVE
└── 05 — SOURCES
```

The repository will grow incrementally. Durable summaries, project checkpoints, source references, and working-state handoffs should be stored in the appropriate layer rather than added as an undifferentiated archive.
