# Deck Lab 0.1.15 — chosen-type reducers, imprinted reducers, and Darkness Crystal replacement/reanimation

## Evidence / Oracle rules

- **Cloud Key:** As this artifact enters, choose artifact, creature, enchantment, instant, or sorcery. Your spells of the chosen type cost {1} less. Choice is recorded once per battlefield instance. Oracle: https://www.fetch-mtg.com/cards/cloud-key
- **Semblance Anvil:** ETB optional imprint exiles a **nonland card from the controller's hand**. Spells you cast sharing **any card type** with the imprinted card cost {2} less; multiple shared types do not multiply the discount. Oracle/rulings: https://www.mtgdatabase.com/en/archive/319-Scars-of-Mirrodin/card/32137-Semblance-Anvil
- **The Darkness Crystal:** If a nontoken creature an opponent controls would die, instead exile it and you gain 2 life. Its paid `{4}{B}{B}, {T}` activation puts a targeted creature card **exiled with this same Crystal** onto your battlefield tapped with **two additional +1/+1 counters**. Tokens can die normally. Death triggers should **not** occur for replaced deaths. Official Final Fantasy release notes: https://magic.wizards.com/en/news/feature/final-fantasy-release-notes

## Implemented / bounded behaviours

1. **Dynamic cost quote:** `spellCostQuote` integrates Cloud Key's chosen type and Semblance Anvil's nonland hand card imprint with preexisting 0.1.14 static reducers, preserving generic floor zero, coloured pips, commander tax and printed mana value. The game saves `costChosenType`, `imprintCardTypes`, `imprintCardId` and `imprintResolved` on the source instance, resets choices when source leaves play, and displays chosen/imprinted status on the card inspector. Source choices are explicit and cannot be overwritten; declining an imprint gives no reduction. Imprinted card is really exiled and linked by unique source ID. A cost-reducing source tapped on battlefield still applies.
2. **Creature death gateway:** `departureToGraveyard` checks the controller of a creature versus the controller of a live opposing Darkness Crystal on battlefield. For a **nontoken** creature that would die, it moves the actual card to its **owner's exile** with `exiledBy.sourceId` and grants Crystal controller 2 life. The old death queue is not emitted on that path. This is used from lethal damage/state cleanup, named destroy-spell resolution, explicit manual battlefield-to-graveyard movement, and Zombie sacrifices in Empty the Laboratory. Token deaths and own creatures remain ordinary deaths.
3. **Paid linked reanimation:** The Darkness Crystal's inspector selects a qualifying creature in either owner's exile **linked to that exact Crystal instance**, pays `{4}{B}{B}` with the ordinary mana planner (never discounted as a spell), taps the Crystal and returns the card under controller's control **tapped** with two +1/+1 counters. Source-specific links prevent using a different Crystal. Crystal-exiled cards are no longer presented as freely castable; the proper activation is the supported action. Activating is restricted to the active player's main phase with empty stack in the bounded practice engine.
4. **Interactive UI:** Cloud Key spell-type selection, Semblance Anvil hand-card imprint/decline, Crystal linked-creature selection and activation are explicit card-inspector actions with readable target labels and disabled invalid choices. Existing manual override controls remain available and clearly recorded as manual.

## Limits / unobserved

- Choice timing for Cloud Key's **as-enters** replacement and Semblance Anvil's **ETB trigger** is represented as an explicit pending inspector action. The engine does not yet put either choice on a fully interactive stack or force selection before all other actions. Users must choose as the permanent enters.
- **Simultaneous destruction:** The official special case where The Darkness Crystal leaves simultaneously with nontoken opposing creatures (e.g. a board wipe) still requires manual adjudication, since the bounded simulator lacks atomic multizone state events.
- **Multiple competing replacement effects**, graveyard prevention, commander zone/exile replacement choices and complete APNAP/ETB ordering remain unmodeled. Multiple Darkness Crystals use deterministic first-source handling, not player-chosen replacement ordering.
- The Crystal activated return uses immediate resolution rather than fully stack-based priority. It does **not** create a casting permission for other linked-exile cards.
- No general Oracle interpreter, hybrid/X/alternative cost support or other dynamically chosen type modifiers. Legacy Tribal renamed Kindred differences and unusual card-face type changes need further rules integration.
- The simulator is a practice helper, not a verified competitive-rules engine. Physical Android device testing has not been performed by CI.
