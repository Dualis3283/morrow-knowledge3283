# Deck Lab 0.1.17 — Token replacement multipliers, Reflections spell copies, legend choice

## Context / evidence

Continuation of MECH-023, where Necroduality and manual token copy were verified. Parallel Lives, Anointed Procession, Adrix and Nev, Twincasters, Mondrak, Glory Dominus and Doubling Season double **tokens an effect would create**. Each independent replacement doubles the resulting count: e.g. one effect with two different applicable doublers creates four. Doubling Season has an additional **counter** replacement not implemented here. Primary official rules: https://magic.wizards.com/en/news/feature/secrets-of-strixhaven-release-notes (Adrix); https://magic.wizards.com/en/news/feature/teenage-mutant-ninja-turtles-release-notes (Doubling Season); https://mtg.wtf/card/wot/103/Parallel-Lives .

**Important distinction:** Reflections of Littjara chooses a creature subtype as it enters, then copies a matching **spell** on cast. When a copy of a permanent spell resolves, it enters as a token permanent, but that event does **not** create a token; token-creation doublers do not apply. Its copied creature enters before the original spell. Official 2021 Kaldheim release notes: https://magic.wizards.com/en/news/feature/kaldheim-release-notes-2021-01-22 . Legend rule: comprehensive rule 704.5j: if a player controls multiple legendary permanents with the same name, that player chooses one and places the others into their owners' graveyards (tokens cease to exist). Source https://magic.wizards.com/en/rules .

## Bounded implementation

- Static named token-creation replacement effects from **Parallel Lives, Anointed Procession, Doubling Season, Adrix and Nev, Twincasters, Mondrak, Glory Dominus** under the **token controller** multiply created-token counts. A shared `tokenCount` path is used by normal named token-producing spells, Ovika/Iconoclast/Thopter triggers, Shorikai Pilot tokens, Necroduality triggered token copies and manual source-linked copies. Counts capped at 128 in an event; excess is rejected atomically, never silently truncated. Public log records source instance IDs and count changes. Doubling Season's +1/+1 and loyalty-counter replacement remains **manual**. Other token multipliers outside this whitelist remain manual.
- **Reflections of Littjara:** normal paid `{4}{U}` enchantment, card inspector records one creature **subtype** (e.g. Zombie) as a bounded as-enters choice. Matching **creature spells** queue a source-linked counterable spell-copy trigger above the original. Resolving it creates a single `isToken` permanent-copy using printed copyable values, `createdBy.mode='spell-copy'` and `spellCopyNotCreated=true`; therefore the above token doublers do not apply. Noncreature Kindred spell copies and unusual spell alterations remain manual. The Reflections choice resets when it leaves the battlefield.
- **Legend rule:** after each public engine action, detect multiple **legendary permanents with the same name controlled by one player**. For human-controlled duplicates, pause with persisted `pendingLegend` and a modal of exact permanent IDs to select the one kept; all other tokens cease to exist and real permanents leave the battlefield for owner graveyard (subject to the existing bounded death replacement rules). No unrelated action can advance until the selection is made. Scripted opponent picks non-token first then stable ID deterministically, with an audit entry. Commander replacement and the full comprehensive-rules layer system remain manual.
- **Token transparency:** UI labels Reflections results as **TOKEN / SPELL COPY** and states *not created, so token doublers do not apply*. All other copied tokens retain source/target provenance. Existing normal token inspector is preserved.

## Tests and limitations

11 new deterministic tests (211 total locally) verify each named reducer's partial coverage, 1→2 and 1→4 multiplication, controller-specific doubles of manual tokens, Reflections's spell-copy priority and prevention of double-counting, type selection, persisted human legend rule choice, preserving original/choosing token, deterministic opponent legend, and atomic 128-token cap. New Playwright checks mobile 390px and desktop 1440px cover manual doubled copies, subtype selector, paid matching spell, Reflections' **non-created** token, on-screen legend choice and save/reload. Prior 200 deterministic and browser tests retained. Reworked old test illegally placing two legendary Darkness Crystals under the same controller: tests same linked-exile source behaviour with legal board transitions.

**Open:** as-enters timing is still manual selector for Reflections, full MTG copyable-value/counter/replacement/layer rules, token-entry event batching/APNAP, multiple competing replacement effects and choices, automatic ETB events from complex copied card text, legendary names affected by continuous effects, commander graveyard/exile choices and conditional/dynamic doublers. Full interaction-driven priority is incomplete. Physical Android-device install not observed. This is a bounded practice engine, not authoritative tournament simulation.
