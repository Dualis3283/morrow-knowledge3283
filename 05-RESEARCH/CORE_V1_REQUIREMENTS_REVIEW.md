# Morrow Core — Requirements Review R1

**Date:** 14 October 2026. **Status:** Internal preliminary review; not owner sign-off, independently audited conformance or v1.0 ratification.

**Sources checked:** Core RFC 0001 (MC-01–15), Ethos, Operating Model, Consistency Protocol, Relational Context Ruleset, Context Bridge and Strategic Direction.

| IDs | Finding | Proposed correction |
|---|---|---|
| MC-01/02 | Earlier ladder mixed current user intent with external facts | Resolve intent conflicts through current authorized instructions; empirical claims through verified observations |
| MC-03/04 | Appropriate; provenance may be self-asserted | Preserve source/status; schema validity is not evidence authentication |
| MC-05/06 | Useful; risk of forced analogies | Record material differences and only present relevant alternatives |
| MC-07 | Preference is not objective fact | Preserve changed decisions and higher-priority permission/safety limits |
| MC-08 | Unlimited deletion promises are untestable | Bound assertions to controllable stores; verify downstream erasure separately |
| MC-09/10 | Successful tool call is not verified outcome | Distinguish receipts from readbacks/tests, and disclose missing checks |
| MC-11 | Mandatory retention may violate privacy | Correction storage only when authorized and proportionate |
| MC-12/13 | Supersession and inspectability appropriate | Retain only permitted history, no demand for hidden reasoning |
| MC-14 | Verification overhead could make process unusable | Stateless/low-risk compact operation remains valid |
| MC-15 | Syntactic portability is not cross-model behavior | Model evaluations and independent assessment required |

## Open gates
1. Repository already has GPL-3.0. Clarify scope for text, schema and runtime code without silent relicensing.
2. Define measurable applicability, severity and review threshold for normative requirements.
3. Design authenticated consent, minimization, deletion, version migration and source-trust contracts.
4. Evaluate cross-model behavior with matched controls; do not mistake a successful JSON parse for AI understanding.
5. Preserve Phase 6 baseline as 19/20 workflows and unfrozen.

**Decision state:** Candidate refinements only. The approved strategic goal remains intact; the current PR remains a draft and main is not modified.
